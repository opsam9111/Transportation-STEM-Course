# Transportation STEM Professional Learning Course

This is the expanded functional course-development package for **Teaching Smart, Safe, and Sustainable Transportation: A Foundational Course for Middle School Educators**.

## Included in this stage

- Course homepage and semester overview
- Level 2 course orientation
- Communication, assessment, late-work, accessibility, and responsible-AI expectations
- Course policies and technical-support pages
- Complete Unit 1: Transportation Systems, Communities, and Careers
- Complete Unit 2: Motion, Energy, and Sustainable Transportation
- Complete Unit 3: Sensors, Data, and Real-World Conditions
- Interactive community-journey explorer, relative energy-demand model, and sensor-lighting model
- Knowledge checks, local progress and reflection saving, downloadable reflections, text-size control, contrast control, and browser read-aloud
- Placeholder module cards for Units 4–7 and the final showcase

## Local preview

Open `dist/index.html` in a browser. For complete browser behavior, serve the `dist` directory with a local web server.

## GitHub Pages

Upload the files inside `dist` to the root of a GitHub repository and enable GitHub Pages from the main branch and root folder.

This package is an instructional prototype. Units 4–7 and the final assessment materials will be added in the next development stages.
